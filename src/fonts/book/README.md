# Buchschriften außerhalb von Google Fonts (PROJ-32)

| Datei | Schrift | Quelle | Lizenz |
|---|---|---|---|
| `texgyrepagella-*.woff2` | TeX Gyre Pagella (Palatino-Stil) | CTAN, `fonts/tex-gyre/opentype`, geladen am 2026-11-24 | GUST Font License |
| `texgyreheros-*.woff2` | TeX Gyre Heros (Helvetica-Stil) | CTAN, `fonts/tex-gyre/opentype`, geladen am 2026-11-24 | GUST Font License |

- Die OpenType-Dateien wurden verlustfrei in WOFF2 verpackt (fontTools), Glyphen und Maße sind unverändert.
- Die GUST Font License (`GUST-FONT-LICENSE.txt`) verweist auf die LaTeX Project Public License 1.3c: Weitergabe und gewerbliche Nutzung, auch Einbetten in gedruckte Bücher, sind erlaubt. Für veränderte Schriften wird ein neuer Name erbeten (nicht verlangt). Hier wird nichts verändert.
- Die übrigen Buchschriften (PT Serif, EB Garamond, Baskervville, Atkinson Hyperlegible) bindet `next/font/google` beim Bau ein, sie stehen unter der SIL Open Font License.
- Lizenzhinweise für die App: `docs/production/prod-umzug.md`, Abschnitt 8.
